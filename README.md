# Pemrograman_MuthiahAfifa_Zircon_TLS26

**Nama:** Muthiah Afifa  
**Kelompok:** Zircon

## Deskripsi

Repository ini berisi implementasi tugas Pemrograman Dasar TLS 2026.
Terdapat dua program dalam bahasa C++, yaitu:

1. **The Last Astronaut** — program untuk menentukan urutan eliminasi dan astronaut terakhir berdasarkan aturan perhitungan K.
2. **Alien-In-The-Middle** — program untuk mengenkripsi pesan berdasarkan nilai huruf saat ini dan huruf sebelumnya.

Program dibuat menggunakan bahasa C++ dan mengikuti ketentuan yang diberikan pada tugas.
